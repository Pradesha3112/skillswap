

# 🚀 SkillSwap – Peer-to-Peer Skill Exchange Platform

## 📌 Overview

**SkillSwap** is a web-based digital platform that enables users to exchange skills without monetary transactions. Users can list skills they can teach and skills they want to learn, and the system matches users for peer-to-peer learning. The platform aims to democratize education and promote collaborative learning communities.

---

## 🎯 Problem Statement

Many students and young professionals cannot afford paid courses and mentorship programs. Existing platforms focus on paid learning and freelancing, but there is no structured digital system for mutual skill exchange. This creates a gap in accessible learning and community-driven skill development.

---

## 💡 Proposed Solution

SkillSwap provides a **peer-to-peer skill exchange ecosystem** where users act as both learners and mentors. The platform matches users based on complementary skill requirements and enables structured knowledge sharing.

---

## 🧩 Key Features

### ✅ Core Features

* User Registration and Login
* Skill Listing (Skills to Teach & Learn)
* Skill Matching System
* User Dashboard
* Profile Management

### 🌟 Advanced / Future Features

* AI-based skill recommendation
* Skill credit system (earn credits by teaching)

* Certification badges

## ⚙️ Installation & Setup

### 🔹 1. Clone the Repository

```bash
git clone https://github.com/Pradesha2005/SkillSwap.git
cd SkillSwap
```

### 🔹 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 🔹 3. Run the Application

```bash
python app.py
```

### 🔹 4. Open in Browser

```
http://127.0.0.1:5000/
```
